# STX branding

The owner supplied the monochrome and color STINTRIX references and requested these project-specific variants. Edits used the built-in image generation tool. Both source images stay local to the repository; build-time code only resizes and encodes them into PNG/ICO resources. Original reference files are untouched.

- `src/branding/stx-app.png`: complete STX + STINTRIX logo, white on black.
- `src/branding/stx-menu.png`: yellow-green and white logo, black menu banner.
- Generated Windows icon sizes: 16, 32, 48, 64, 128 and 256 pixels. The complete mark is retained at every size.

Preserve the full original composition, connected angular STX racing monogram above, and the entire small STINTRIX wordmark below, spelled S T I N T R I X. The small STINTRIX text is mandatory; do not remove or omit it. Preserve its stylized typography, negative spaces and relative proportions. Keep a square canvas and the complete two-level logo centered with generous black margins as in the supplied reference. Faithfully retain the original geometry and layout; no new design, no added symbols, no border, no gradients, no textures, no glow, no shadows. Flat high-contrast white-on-black application branding, including BOTH the large STX monogram AND the lower STINTRIX text.

## Transparent menu variants (0.2.2)

The menu uses genuine alpha transparency. The dark variant is off-white and yellow-green; the light variant is charcoal and olive yellow-green. Both preserve the STX and STINTRIX marks. The Windows EXE icon remains the original opaque white-on-black logo. Only menu PNG encoding retains alpha; no background rectangle is added.
