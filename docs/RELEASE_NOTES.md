LMU StintLab 0.1.0: independent Windows x64 telemetry HUD and offline analysis.

Extract the complete portable ZIP and run Start.cmd. No Python installation or game file changes are required. Demo.cmd provides synthetic telemetry. Source downloads use Setup.cmd to install Python 3.13 and checksum-verified dependencies.

Includes input curves, raw / filtered controls, throttle / brake bars, steering display, automatic recording, complete-lap A / B and cross-session comparison, offline trajectory replay and telemetry analysis.

Private recordings and local settings are excluded. Public map backgrounds are omitted pending clear redistribution permission; recorded world / GPS trajectories provide the track view. See README and third-party notices for requirements and licensing.
