# 使用说明 / Usage

1. 把解压目录放在普通可写文件夹。源码运行 `Setup.cmd`；便携包直接运行 `Start.cmd`。
2. 进入 LMU 驾驶会话。HUD 的 WAIT 变为 REC 后自动采集；结束会话或正常退出 HUD 时完成保存与分析。
3. 右键 HUD：打开设置、选择原始 / 过滤后输入、切换纯净模式、会话库或打开当前记录。退出请用菜单正常关闭，确保后台写入和分析完成。
4. 会话库中选一场已完成记录，选择 **圈 A / 圈 B**。只允许结构完整的圈；缺起终点、遥测断层、重复圈号等记录不能用作完整圈对比。无效圈 / 进站圈的标记保留，自动最快参考圈会排除不合格圈。
5. HTML 报告可以离线打开；拖动播放时间查看曲线和轨迹。赛道区域用滚轮缩放、拖动平移、重置回到全图。跨比赛对比应使用相同车辆和赛道，天气、燃油、轮胎差异会影响结论。
6. 原生 LMU 记录可从菜单导入或运行 `Start.cmd --import-duckdb "完整文件路径"`；源数据库只读，生成文件保存在 `data/ImportedLogs/`。先等待游戏关闭并结束该记录。

快捷入口：`Demo.cmd` 使用合成数据；`Start.cmd --clean` 只显示曲线；`Start.cmd --clean-controls` 同时显示曲线、柱形图和方向盘；`Check.cmd` 检查环境。

默认 120 Hz。设置中的 1–4000 Hz 是目标轮询 / 绘制频率，动态模式可设最小 / 最大频率和变化阈值。实际新数据速率不会超过 LMU 的提供频率；高设置也受 CPU、显示器和 Windows 定时器限制。诊断窗口可查看实际速率、错过周期、队列和记录状态。不要把重复读取次数当成新的物理采样。

发现不到游戏目录时，仍可直接读取共享内存；目录只用于原生记录文件选择的起始位置。源码可运行 `Setup.cmd -GameDirectory "你的游戏目录"`；便携包可在根目录创建 `local_settings.json`：

```json
{"data_directory":"data","game_directory":""}
```

也可用 `LMU_STINTLAB_DATA_DIR` 环境变量指定私有数据目录。不要指向游戏安装目录或公开源码目录。现有设置保留，Setup 不覆盖用户采样偏好。

打不开 HUD 时先运行 `Check.cmd`，查看 `data/startup_error.log`。打不开地图时检查记录是否具有世界坐标 / GPS。独占全屏请改为无边框窗口。此工具不提供游戏控制或输入注入。
