# 控制中心与 RaceCom 原版报告

直接双击 `LMU-StintLab.exe`（兼容 `Start.cmd`） 打开控制中心。`--hud`、`--demo`、`--clean`、`--clean-controls` 保留直接启动 HUD 的方式。

| 页面 | 操作 |
| --- | --- |
| 运行与 HUD | 启停、演示、输入通道、波形窗口、纯净模式、附加遥测面板 |
| 赛事复盘 | 搜索赛事、直接打开 Review / 圈速单 / 比赛日志、导出 ZIP |
| 曲线对比 | 同场完整圈 A / B、同车同赛道跨场最快圈、实时参考圈 |
| 采样与遥测 | 固定 / 动态采样、同步绘制、车型阈值、燃油、进站、Stint、天气参数 |
| 图像与数据 | RaceCom 生成器、兼容版式、赛事包导入导出、官方遥测只读导入 |

实时 HUD 保留所有驾驶阶段；自动写盘仅限 LMU 会话码 5–8（排位）和 10–13（正赛）。练习、Warmup、未知阶段不录制。演示是独立合成记录；手动导入历史练习记录仍可查看。旧文件不删除。

选择用户自有的 `Image Generate.exe` 后，通过独立适配模块写出 `_racecom/laps.xlsx`、`race_log.txt`、`race_log.json`，后台静默调用原版浅色图像生成器。程序及 Source 图片保持原位；原版排版不重绘。车辆裁切可沿用用户在原版生成器中已有的校准。

输出 `圈速单.png` 和 `比赛日志.png` 在该场赛事文件夹里，赛事包自动包含它们。没有完成圈的会话只生成比赛日志。图像生成有超时控制，失败保留遥测和已有图片，可从控制中心重试。更换生成方式时旧报告备份到 `_report_history/`。

原版会重算最快圈。PIT、部分记录、缺圈、有效性未知的圈导出为 **统计无效**，保留 `game_valid` 原始标志，仅排除报告统计，不代表游戏处罚；排除原因显示在备注和时间线中。分段、名次缺失显示原版空值符号；出界边界估算不会充当官方警告数。

公开包未附带 RaceCom EXE、商标或车型照片；配置只在 `data/renderer_settings.json`。未配置不自动切到不同版式；选择 `native` 才使用 StintLab 兼容样式，演示例外。

窗口按系统 DPI 和品牌字宽布局，宽屏设置卡片并排，窄屏自动纵向排列。页面、导航、按钮、滚动与开关使用短过渡动画；过渡完成取消帧调度。内容不使用整窗透明，避免背后文字透入。
